# Liste de contrôle

Exécute ce contrôle avant chaque livraison.

## Contrôles mécaniques

Recherche chaque forme hors du code et des citations.

| Recherche | Problème | Correction |
|---|---|---|
| `;` | Phrase trop liée | Écrire deux phrases. |
| `devrait`, `pourrait` | Obligation ou possibilité ambiguë | Écrire « doit », « peut » ou donner le fait. |
| `afin de` | Forme longue | Écrire « pour ». |
| `dans le cas où` | Forme longue | Écrire « si ». |
| `il convient de noter` | Remplissage | Supprimer et donner le fait. |
| `au niveau de` | Relation imprécise | Écrire « dans », « sur », « pour » ou supprimer. |
| `simplement`, `facilement`, `aisément` | Affirmation non prouvée | Supprimer ou donner une mesure. |
| `robuste`, `puissant`, `complet` | Qualificatif vague | Donner une propriété mesurable. |
| `etc.` | Liste incomplète | Nommer les éléments utiles. |

## Contrôles mesurables

1. Une instruction contient au maximum 20 mots.
2. Une description contient au maximum 25 mots.
3. Un paragraphe contient au maximum six phrases.
4. Une instruction contient une seule action.
5. Une description ajoute une seule information par phrase.
6. Une liste verticale remplace une énumération complexe.

Les commandes, identifiants et valeurs entre accents graves comptent comme un mot.

## Contrôles de sens

1. Chaque passage est une procédure ou une description.
2. Chaque instruction utilise l'impératif.
3. La voix est active quand l'acteur est connu.
4. Chaque condition précède l'action concernée.
5. Chaque avertissement précède l'étape dangereuse.
6. Chaque concept conserve le même terme.
7. Chaque pronom désigne clairement un nom.
8. Aucun fait, chiffre, délai ou résultat n'est inventé.
9. Le code, les commandes, les chemins et les erreurs citées restent exacts.

## Rapport de contrôle

Pour chaque problème, donne :

1. le numéro de la règle ;
2. le texte concerné ;
3. une réécriture conforme.

Si l'utilisateur demande une conformité ASD-STE100, précise que cette norme concerne l'anglais. Cette adaptation française ne peut pas produire une conformité ASD-STE100.
